Setup

Set a Google Gemini API key for personal mode, or leave it blank if this app is configured to use your backend quota.

Get a free key at aistudio.google.com/app/apikey. If you add your own Gemini keys here, they stay on your device for your own use and Gemini requests will go directly from your app instead of being sent to our backend.

Add more personal keys to support more requests per minute (RPM), One free key can support 15 RPM Only above that need to create a new free key deleting the old one.

WebLLM runs entirely in your browser using WebGPU. No server configuration needed. The AI model will be downloaded on first use (~500MB).
