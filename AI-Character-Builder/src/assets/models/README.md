Local WebLLM model files go in this folder.

Expected layout:

src/assets/models/local-gemma/
  - mlc-chat-config.json
  - tokenizer.json and related tokenizer files
  - the WebGPU wasm library referenced by environment.ts
  - model weight files as generated by MLC LLM

For Gemma 3 1B, the downloader expects the MLC repo layout under
`src/assets/models/gemma3/1b/`.

The app is configured to look for the model id `local-gemma` first.
If the files are not present, WebLLM will fall back to the built-in packaged model.
