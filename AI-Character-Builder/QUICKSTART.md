# QUICK START

🚀 **Ready to run?** Follow these 3 steps:

## 1️⃣ Install Dependencies
```bash
cd "c:\coding\AI-Character-Builder"
npm install
```

## 2️⃣ Get Free API Key
Go to: https://huggingface.co/settings/tokens
- Sign up (free account)
- Create a new token
- Copy it

## 3️⃣ Start the App
```bash
npm start
```

**The app will open automatically at http://localhost:4200**

---

## First Time Setup

1. Click ⚙️ button (top-right)
2. Paste your Hugging Face API key
3. Click Save
4. Select a character
5. Start chatting!
